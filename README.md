# 📽️ Baran PowerPoint — Slides + AI (MIT)

Presentation app by Baran Avisat. UI in EN/TR/AR. Static + README.

## Editor

8 layouts (title/bullets/two-col/image-right/quote/section/table/blank),
rich-text toolbar, per-slide background, 6 themes, transitions
(fade/slide/zoom) in fullscreen present mode, speaker notes, filmstrip +
up/down reorder, duplicate/delete, undo (40 snapshots), images, tables,
multi-deck autosave (localStorage), JSON/HTML/TXT export, print-to-PDF.

## On-Device AI (no server)

Outline (`#`/`-`) → slides with auto-layout, layout suggester, notes
expander, wordiness check. All local.
